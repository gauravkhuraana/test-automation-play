# 🎯 Test Automation Practice Hub

A comprehensive training ground for test automation engineers built with React, TypeScript, and Vite.

## 🌐 Live Demo

Visit the live application: **[https://gauravkhuraana.github.io/test-automation-play/](https://gauravkhuraana.github.io/test-automation-play/)**

## 🚀 Features

This website contains every common scenario you'll encounter in real-world test automation projects:

- **Basic Elements**: Fundamental form controls and basic interactions
- **Intermediate UI**: Complex user interactions and dynamic behaviors  
- **Advanced Features**: Challenging scenarios that break many automation scripts
- **Business Flows**: End-to-end user journeys and complete workflows
- **System Features**: Browser APIs and system-level functionality
- **Complex Scenarios**: Real-time updates and challenging edge cases

## 🛠️ Development

### Prerequisites
- Node.js 20+
- npm

### Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🚀 Deployment

This project is automatically deployed to GitHub Pages using GitHub Actions.

### How it works:
1. When code is pushed to the `main` branch
2. GitHub Actions runs the build process
3. Generated files are deployed to GitHub Pages
4. Site is available at: https://gauravkhuraana.github.io/test-automation-play/

### Manual Deployment:
You can also trigger deployment manually from the Actions tab in GitHub.
